UNIT ENGINE

Representation
  Dimension: exponents of [m, kg, s, A, K, mol, cd]; rational exponents allowed
             (roots), comparison epsilon 1e-9.
  Unit:      name, dimension, factor to SI, affine offset (temperatures).
  Quantity:  si value + display unit.  si = value * factor + offset.

Arithmetic rules
  +, -   dimensions must match; result keeps the left operand's unit.
  *, /   dimensions combine; results simplify to a named coherent SI unit when
         one exists (N, Pa, J, W, ...), otherwise to base-unit composition.
         Quantity op Unit preserves the compound unit name (kN/m).
  ^      exponent must be dimensionless; dimension is scaled.
  Affine temperature units (degC, degF) are rejected in *, /, ^ operations.

Supported families
  SI base and derived, metric prefixes (Y..y, incl. u/µ/μ), imperial length,
  mass and volume, pressure (bar, atm, psi, torr, mmHg), energy (cal, Wh, BTU,
  eV), power (hp), time (min, h, day, week, yr), angle (rad, deg, rev),
  electrical (A, V, ohm, S, F, H, T, Wb, C), temperature (K, degC, degF, R).

Python interoperability
  codegen emits `ureg.<unit>` expressions; the runtime reports quantities as
  { si, unit } so the SI value survives the boundary unchanged.
